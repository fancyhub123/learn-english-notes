# learn-english-notes

从 YouTube 视频的英文字幕生成的 CET-4（四级）英语学习笔记。

## 目录结构

按「频道 → 视频」两级组织，每个视频一个文件夹，内含一份 `<标题> 学习笔记.md`，每份笔记包含三部分：

- **单词**：美式音标 / 中文释义 / 原文句子（句中目标词加粗）
- **词组**：美式音标 / 中文释义 / 原文句子（句中目标词组加粗）
- **经典句子**：原文 / 中文翻译 / 用法要点

## 现有内容

- **Dartmouth** — 2024 Commencement Address by Roger Federer
- **David Senra** — Building Muse, Working with Mark Zuckerberg & The Future of AI
- **The Diary Of A CEO** — Mark Cuban、Ray Dalio

## 说明

笔记由脚本从英文字幕自动提取生成，仅供个人英语学习使用；原文句子均摘自对应视频，版权归原作者所有。
